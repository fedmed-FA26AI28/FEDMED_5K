--- Line 62 ---
VN: * **Bản chất & Kiến trúc**: Mục tiêu tối thượng là xây dựng **MỘT MÔ HÌNH TOÀN CỤC DUY NHẤT (Single Global Model)**. Do đó, **trọng tâm tối ưu nằm ở phía MÁY CHỦ (Server-side)**: Server tận dụng "góc nhìn toàn cảnh" (Global View) để điều phối, khử trôi dạt gradient (Client Drift), chuẩn hóa trọng số tổng hợp hoặc chia sẻ tri thức toàn cục.
EN: * **Architecture & Philosophy**: The fundamental objective is to train a **SINGLE GLOBAL CONSENSUS MODEL**. Consequently, the primary optimization locus resides on the **SERVER (Global-side)**: The server leverages its global vantage point to orchestrate parameter updates, eliminate Client Drift, normalize aggregated weights, or broadcast global distribution priors.

VN: * **Các giải thuật tiêu biểu**:
EN: * **Key Algorithmic Paradigms**:
--- Line 64 ---
VN: - **FedAvg** *(McMahan et al., 2017)*: Baseline kinh điển, Server trung bình trọng số theo số lượng mẫu. Dễ mất ổn định khi Non-IID cao.
EN: - **FedAvg** *(McMahan et al., 2017)*: Classical baseline, Server executes sample-weighted parameter averaging. Prone to severe drift under high Non-IID skew.
--- Line 65 ---
VN: - **FedProx** *(Li et al., 2020)*: Thêm thành phần điều chuẩn Proximal Term $\frac{\mu}{2} \|w - w_t\|^2$ ghìm khoảng cách giữa trọng số client và mô hình Server toàn cục; chịu lỗi tốt khi có client tính toán chậm (*stragglers*).
EN: - **FedProx** *(Li et al., 2020)*: Introduces a proximal regularization term restricting local updates from straying too far from the global server parameters; tolerates system stragglers.
--- Line 66 ---
VN: - **SCAFFOLD** *(Karimireddy et al., 2020)*: Server duy trì và cập nhật biến đối chứng toàn cục (*Global Control Variates*) để ước lượng hướng trôi dạt trung bình và bù trừ gradient cho các client.
EN: - **SCAFFOLD** *(Karimireddy et al., 2020)*: Server maintains and updates Global Control Variates to explicitly estimate drift directions and correct client gradient paths.
--- Line 67 ---
VN: - **FedNova** *(Wang et al., 2020)*: Server chuẩn hóa và tái cân bằng trọng số tổng hợp theo số bước tính toán thực tế của từng client, tránh thiên lệch về phía client chạy nhiều bước.
EN: - **FedNova** *(Wang et al., 2020)*: Server normalizes and rescales aggregation weights based on each client's actual computational steps, avoiding bias toward clients executing more local epochs.
--- Line 68 ---
VN: - **Server Momentum & Adaptive FL** *(FedAvgM, FedAdam)*: Server coi vector tổng hợp như một gradient giả và tối ưu hóa bước cập nhật toàn cục bằng momentum / adaptive learning rate.
EN: - **Server Momentum & Adaptive FL** *(FedAvgM, FedAdam)*: Server treats aggregated client updates as a pseudo-gradient, optimizing the global update trajectory with momentum and adaptive learning rates.
--- Line 69 ---
VN: - **FedSLD** *(Luo & Wu, ISBI 2022 - Đề tài tham khảo)*: Server tổng hợp tỷ lệ các nhóm bệnh thành **Phân Phối Nhãn Toàn Cục (Shared Label Distribution)** rồi phát xuống để từng client căn chỉnh hàm mất mát (*Logit Adjustment*), giải quyết triệt để vấn đề lệch nhãn trong ảnh y tế.
EN: - **FedSLD** *(Luo & Wu, ISBI 2022 - Project Reference)*: Server aggregates client class frequencies into a **Shared Label Distribution** and broadcasts it back to calibrate local loss functions (*Logit Adjustment*), thoroughly resolving multi-center label skew.
